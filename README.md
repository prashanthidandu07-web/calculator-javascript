PROJECT OVERVIEW
This project is a fully functional calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations through an interactive user interface. The project was developed to strengthen core JavaScript concepts such as DOM manipulation, event handling, conditional statements, string methods, and error handling.

 Features

- Perform Addition, Subtraction, Multiplication, Division, and Percentage operations
- Clear (C) functionality
- Delete (DEL) functionality
- Real-time display updates
- Error handling using try...catch
- Responsive user interface
- Clean and interactive design using CSS Grid and Flexbox

 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

 JavaScript Concepts Used

- DOM Manipulation
- Event Listeners
- Callback Functions
- Variables (`let`, `const`)
- Conditional Statements (`if`, `else if`, `else`)
- String Methods (`slice()`)
- `eval()`
- `try...catch`
- `querySelectorAll()`
- `forEach()`
